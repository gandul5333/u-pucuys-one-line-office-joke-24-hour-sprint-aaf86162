One funny line about office life, at most 200 characters — the sort you'd send a colleague after a meeting that should have been an email. `main.ts` (Node 22+, no dependencies) writes the line to `/output/entry.txt`.

> I told my manager that meeting could have been an email, so he booked a meeting to discuss my attitude toward meetings.

119 characters, one sentence. An everyday truth (everyone has sat in a meeting that should have been an email) with the surprise at the end: the punishment for complaining about meetings is more meetings — a meeting about your attitude toward meetings.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.txt` (UTF-8, one line, 119 characters).
